# 可视化处理流程图说明

`02_可视化处理流程图.svg` 只描述本包图表的生成与检查路径，不覆盖数据处理链本身。

1. 读取 `03_结果数据/01_all_sample_supplement.csv`、`04_gate_counts.csv`、`08_cadence_audit.csv` 和 `06_usflux_context_correlation.csv`。
2. 固定图表口径：状态环图使用互斥 `sample_state`，门控图以理论 360 条为参照，时间图使用真实 `T_REC` 并在大缺口处断线。
3. 生成六张结果图：门控、状态、事件返回、时间趋势、OLS 斜率分布和 USFLUX 背景散点。
4. 检查数字合计、SVG/PNG 产物、图例、单位与脚注，并将结果写入 `04_图表/visualizations/`。
5. 通过 `05_复现脚本/` 生成复现日志、manifest、SHA256 清单和正式 ZIP。

每张图的分母与解释边界见 `图表说明.md` 及 `01_主报告/02_可视化与质量评估_20260808.md`。

# 交付与审计说明

正式压缩包位于本目录的上一级：`SHRGT45_全信息基准版_20260808.zip`。它对应当前目录 `SHRGT45_全信息基准版_20260808/`，两者在封存时逐文件核对。

本目录中的文件用途如下：

| 文件 | 用途 |
|---|---|
| `reproduction_log.txt` | 离线重建核心数值链后的结果 |
| `acceptance_check.csv` | 报告、输入、图表、复现与 ZIP 的验收项 |
| `manifest.json` | 机器可读的阅读入口、处理规则和文件路径清单 |
| `file_sha256_manifest.csv` | 除自身以外的所有包内文件的大小和 SHA256 值 |
| `self_test_results.csv` | 数据处理规则和边界条件的自测结果 |

严格前推审计的完整证据位于 `03_结果数据/09_严格对照审计/`，包括 672 条候选门控、NCEI 区间筛查、逐帧关键词核验、6 组原始 JSON、复现脚本和原始检索 ZIP。它与主 Demo 的 37/51 记录队列分开解释。

需要核对文件是否被改动时，以 `file_sha256_manifest.csv` 为准；需要理解结果时，优先阅读主报告而不是直接从审计文件开始。

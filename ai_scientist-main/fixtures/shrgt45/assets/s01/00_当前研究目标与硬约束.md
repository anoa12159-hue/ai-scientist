# 当前研究目标与硬约束

> 文档角色：告诉技术负责人“项目要解决什么、哪些内容不能自行改变、哪些内容可以自行设计”。
>
> 整理日期：2026-08-16。
>
> 适用原则：本文件只汇总当前有效口径，不替代官方在线规则，也不替代各流程中的详细科学合同和实现说明。

## 1. 项目目标

**项目方向（负责人已确认）：**参加 `XH-202619`，选择赛道一、方向二“金乌·太阳物理建模迭代与假设生成”，采用 `B1 x A1`：

- B1“耀斑触发前兆因果链”是科学内核；
- A1 相关的磁场复杂度定量分析是验证引擎；
- A2 时序或多模态材料可以补充证据，但不是主线；
- 不以黑子／`JW-SSD` 分类或单纯提高耀斑预测精度为主线。

**系统目标（负责人已确认，当前总体设计支持）：**构建一个面向太阳耀斑前兆研究的迭代式 AI Scientist。系统从专家给出的候选参数及理由出发，检索和审查资料、形成可检验假设、执行数据验证、检查反例与证据、给出可解释排名和研究判断，再根据人工选择或授权继续迭代。

**Demo 成功标准（当前总体设计）：**证明一条真实、可追溯的自动研究闭环能够跑通。假设得到支持、不支持或证据不足，均可构成有效结果；不要求必须得到阳性结论。

## 2. 当前固定边界

### 2.1 比赛与选题边界

1. 当前赛道、方向和 `B1 x A1` 科学主线不得由技术实现自行改变。
2. 具体技术框架、Agent 数量、模型、数据库、RAG、Skill、工作流引擎和前后端技术栈由技术负责人决定。
3. 比赛规则、时间节点、平台限制和正式提交清单属于动态官方信息，实施前必须重新读取[现行赛事入口与项目选题](../01_比赛要求与官方材料/00_现行赛事入口与项目选题.md)中的两个在线入口。旧 PDF、旧答疑、旧记忆中的相关口径不能直接沿用。

### 2.2 研究流程边界

系统必须保留以下研究链，但可以重构各阶段的技术实现：

```text
专家候选参数与理由
  -> 文献和资料调查
  -> 候选参数评估与选择
  -> 机制整理与可检验假设
  -> 数据计划、取数、处理与统计验证
  -> 反例审查与下一步计划 / 磁图 QA（并列）
  -> 报告与前端展示
```

每一轮至少应能追溯：输入版本、假设、证据来源、数据来源、处理和代码版本、评价口径、支持证据、反对证据、失败记录、人工／系统决策及下一步计划。系统不能只保存最终分数、排名或图表。

### 2.3 当前 SHRGT45 案例的科学边界

以下约束适用于当前首个真实 Demo 案例；若要改变，应明确建立新的研究问题并重新审查，而不是在同一轮中静默修改：

- 当前研究参数为 `SHRGT45`，研究目标为同一空间单位未来 `3-6h` 是否发生 M+ 级耀斑。
- “过去 3h 的 SHRGT45 变化与未来 3-6h M+ 耀斑有关”是待检验的项目／专家先验，不是已有文献已经直接证明的事实。
- 二维观测量最多支持到光球非势性／自由能状态的有限关联，不能据此声称已经证明磁重联、三维拓扑、理想 MHD 失稳或完整因果链。
- 当前全信息 Demo 属于开发性、画像性结果；接入新系统不等于升级为正式确认性科学结论。
- 科学上的“不支持／证据不足”与数据遗漏、标签错误、程序错误、取数失败等“执行失败”必须分开记录。

### 2.4 数据边界

1. 数据源可以使用在线公开数据，也可以使用赛事方数据；**不要求必须使用赛事方数据**。
2. 无论选择哪种数据，都必须记录来源、版本或查询时间、处理过程、用途和必要的完整性信息，使结果可以复核。
3. 赛事方大数据不直接放入移交包，只保留数据说明和下载入口，由技术负责人按需下载。
4. 当前最新 Demo 没有使用赛事方大数据。其数据包主要保存 JSOC 关键词记录、NCEI 事件目录子集、处理规则和派生结果；事件 provenance 仍有 `NEEDS_CLARIFICATION` 项，不能表述成所有来源已经闭合。

### 2.5 决策与输出边界

- 需要改变参数、假设、研究路线或实验规模时，系统应展示候选动作、推荐项、理由、风险和影响，再由人选择；只有用户明确选择“由系统决定”后，系统才获得相应范围的自主权。
- AI 可以在内部形成研究判断并继续获准的研究流程；正式报告、答辩材料和对外科学主张必须由专家确认。
- 预期成果至少包括研究报告和可在前端展示的结果。前端应能表达关键数据、假设状态、证据与反例、评价依据和不确定性；具体页面和可视化形式尚未锁定，由技术负责人提出方案。

## 3. 不属于当前硬约束的事项

以下内容应保留设计空间，不要从旧方案中误读成既定要求：

- 单 Agent 还是多 Agent，以及是否采用图检索、知识图谱或树搜索；
- 当前代码是继续改造还是按接口重写；
- 在线数据和赛事方数据二选一；
- 候选参数排名的具体指标、权重和算法；
- 自主假设树的分支数、预算和停止阈值；
- 前端的具体图表、交互和页面结构；
- 外部 AI Scientist 案例中的具体框架和实现方式。

这些内容可以由技术负责人设计，但不得破坏第 2 节的科学边界、证据可追溯性和人工授权边界。

# SHRGT45 反例下一步验证计划

> 本文件全部内容均为后续研究建议，不代表20260810版本已经执行、获批或通过任何门槛。

- 版本：`曾子晖_反例分析_20260810`
- 统计单位：独立事件/AR；滑动窗和重叠历史记录不是独立样本
- 主时间规格建议：事件前3–6小时、3小时OLS趋势
- 机制边界：SHRGT45只作为二维非势性/自由能积累相关指标

## 一、计划目标

后续验证用于区分：清洁科学反例、数据/标签问题、样本/control/统计规则问题和研究定义问题。它不是用单个反例推翻假设，也不把“证据不足”自动写成“不支持”。

## 二、P0：先解决反例资格问题

### P0.1 冻结6个事件的官方provenance

**所需数据**：GOES/JW-FD官方onset、peak、end、等级、位置、NOAA AR、URL、产品版本、查询时间、原文件SHA-256；保留项目seed原值。

**建议方法**：逐事件双源核对；预先规定等级校准版本、onset容差、跨日匹配和AR缺失补证规则；不根据SHRGT45结果反推标签。

**统计单位**：事件。

**建议通过标准（待组长/学长确认）**：6/6事件字段完整且冲突裁定完成，HARPNUM–AR可追溯，冻结后hash一致。

**未通过时**：仍为 `NEEDS_CLARIFICATION` 的事件只作探索性描述，不进入确认性结论；这不等于假设被否定。

### P0.2 建立独立control合同

**所需数据**：完整M+/X事件起止区间目录、每个control的 `[T0-3h,T0+6h)` 交叠审计、独立安静AR的USFLUX/位置/QUALITY/cadence/周期相位。

**建议方法**：

1. 现有18条同AR记录继续保留，但身份固定为背景演化对照。
2. 任何M+/X区间与 `[T0-3h,T0+6h)` 相交者剔除并保留事件ID证据。
3. 为每个正事件预先匹配至少1个独立安静AR；匹配时不使用SHRGT45或结果指标。
4. 同一AR不得同时进入正组和正式control组。

**统计单位**：独立事件/AR。

**建议通过标准（待组长/学长确认）**：每个正事件至少1个独立匹配control，事件区间交叠为0，全部目录和AR来源可hash复核。

**未通过时**：只有同AR背景演化对照时，不报告正式阴性比较、TSS/HSS/AUC或确认性置信区间。

### P0.3 补像素级质量并复核关键负例

**所需数据**：CMASK、有效像素数/比例、SHARP `QUALITY` 位正式语义、原始磁图、逐帧WCS/配准、三小时历史窗逐帧关键词。

**优先对象**：

1. AR12673唯一正候选：`slope=-0.619838`且 `QUALITY` 非零；
2. 其余10条负斜率正候选；
3. 2条 `|slope|≤0.05` 的近零正候选；
4. strict背景演化对照中的5条正斜率记录。

**建议方法**：对关键记录做不看事件标签的逐帧盲审；检查有效像素/掩码与SHRGT45跳变是否同步；比较主门、`QUALITY=0`、16/16、有效像素稳定和位置门版本；不插值、不压缩缺帧时间轴。

**统计单位**：事件/AR；帧只用于质量审计。

**建议通过标准（待组长/学长确认）**：主效应方向在预注册质量规格下相同，AR级中位差相对主规格变化不超过20%，关键负例不存在掩码、配准或有效像素突变。20%是方案建议阈值，不是既有领域标准。

**需改判为数据/规则问题的条件**：关键负例方向在清洁规格下翻转、效应变化超过20%，或与像素/配准异常同步。

## 三、P1：检验稳健性和AR独立性

### P1.1 时间窗、缺帧和位置门

| 维度 | 主规格建议 | 敏感性规格建议 |
|---|---|---|
| lead-time | 事件前3–6h | 3–4h、4–5h、5–6h |
| 趋势历史窗 | 3h OLS | 2h、4h OLS |
| cadence | 真实T_REC，至少14/16 | 16/16 strict |
| QUALITY | 排致命位 | QUALITY=0 |
| 位置 | `abs(lon),abs(lat)<50°` | <40°、<30° |

现有描述结果中，3–4h、4–5h、5–6h正斜率比例为66.7%、90.9%、54.5%；后续不能挑结果最好的窗口作为主规格。当前 `<30°` 仅AR11158可配对，`<20°`无正候选，不能用本样本决定最佳位置门。

**建议支持标准（待组长/学长确认）**：主规格AR级正-control趋势差大于0且AR聚类bootstrap 95% CI下限大于0；至少两个相邻敏感性窗方向一致。

**建议修正标准**：主规格差≤0且至少两个相邻窗也≤0时，修正“普遍上升”假设；仅单窗异常时标为规则敏感。

### P1.2 留一AR和扩大独立样本

当前AR11158占全部记录49.1%，AR11158+AR11429占正候选81.1%；剔除AR11158后，AR级中位差非加权均值变为 `-0.055963`。

**建议设计目标（待功效分析及组长/学长确认）**：

- 对预先定义的最小科学效应达到至少80%功效；
- 任一AR占独立统计单位不超过10%；
- 留一AR后主效应方向不变；
- 同一AR记录不跨训练/检验或正/control组。

若留一AR方向翻转，只报告AR异质性，不报告总体稳定关联。

### P1.3 按AR控制USFLUX

当前pooled `SHRGT45–USFLUX` Pearson `r=-0.424273`，但AR11158全记录为 `+0.943390`，AR内中心化后为 `-0.245601`。

**建议方法**：每个事件先形成一个3–6h摘要；报告pooled、逐AR、AR内中心化三套关系；扩样本后拟合 `slope ~ cohort + centered_USFLUX + cohort×centered_USFLUX + AR效应`；使用AR聚类bootstrap。

**建议支持标准（待组长/学长确认）**：控制USFLUX和AR后，正候选与独立control的AR级趋势差仍为正，聚类bootstrap 95% CI下限大于0。

**建议收窄标准**：控制USFLUX/AR后效应消失或反向，则将SHRGT45收窄为“与磁通背景共同变化的非势性指标”，不称其具有独立方向性前兆证据。

## 四、P2：研究适用范围修饰因素

只有provenance、control、像素质量和统计独立性全部通过后，仍存在的负例才进入物理适用范围分析。

**建议补充变量**：MEANALP/α作为二维twist代理、confined/eruptive标签、背景约束场的二维代理或文献先验、磁图/剪切图。

**候选问题**：

- SHRGT45上升是否只在某些USFLUX/α范围内出现？
- AR12673型负例是否在清洁数据和独立事件中重复？
- 高SHRGT45但不爆是否与confined状态或更强约束有关？

**建议支持标准（待组长/学长确认）**：清洁负例在新增因子分层后形成可重复条件模式，且跨AR留一法方向稳定。

**建议修正标准**：清洁负例无一致修饰模式，或主方向在扩展独立AR上稳定为非正时，收窄或放弃“事件前普遍上升”的方向性部分。

## 五、建议实施顺序与产出

1. `P0-provenance`：冻结6事件官方事实表和hash。
2. `P0-control`：建立独立control合同，同AR记录单列为背景演化对照。
3. `P0-measurement`：补CMASK/有效像素并复核关键负例。
4. `P1-window`：运行时间窗、QUALITY、缺帧和位置门矩阵。
5. `P1-AR/USFLUX`：事件级汇总、留一AR、USFLUX分层和聚类bootstrap。
6. `P2-scope`：只对通过前述门的清洁反例分析α/约束因子。

若后续获批执行，每一步应输出配置、输入hash、行级纳排原因、事件/AR级结果表和运行日志。机器可读的优先级、所需数据、统计单位和建议通过/修正标准见 `验证优先级与通过标准表.csv`。

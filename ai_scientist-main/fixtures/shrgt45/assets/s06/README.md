# AR11158 固定三例磁图交付落实（2026-08-09）

本目录落实队长与上游最终确认的三个样本。当前绘图单位是“一个固定样本的一个 T0”，因此总计 3 个 T0、每个 T0 拉取 Br/Bp/Bt 三个分量，共 3 幅四联图和 9 个 FITS 文件。`16/16` 是每个 T0 之前 3 小时关键词历史窗的完整性指标，不是要求再画 16 帧。

## 三个案例

1. `POSITIVE`：T0 后 0--3 小时无 M+，3--6 小时发生 M+，属于主例。
2. `BUFFER_EDGE`：事件起始于 T0 后 0--3 小时，作为近时窗/缓冲案例展示，不进入 3--6 小时主分析。
3. `SAME_AR_TEMPORAL_CONTROL`：同一 AR 的较早时段，T0 前 3 小时及未来 0--6 小时均无 M+。它控制活动区身份差异，只是同 AR 时间对照，不是独立安静活动区阴性样本。

缓冲案例中的 X3.3 事件从 01:44 持续至 02:06，完整事件区间同时与 0--3 小时及 3--6 小时窗口重叠。案例归类依据是事件的起始时刻位于 0--3 小时；这不是两次事件。

## 使用边界

- 上游固定 T_REC 原样拉取，不按图像效果挑帧，不使用相邻帧替换。
- 磁图用于技术检查和案例展示，不构成统计检验、预测性能或因果证据。
- 项目种子标记为 X2.2，NCEI 同一起始时刻目录记录为 X3.3，来源状态仍为 `NEEDS_CLARIFICATION`；正文必须保留这一差异。

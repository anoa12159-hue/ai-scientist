## 3. 血缘与包边界不变量

1. 每个包拥有独立 `SourcePackageRef`、tree hash、成员命名空间和 `SourceAssetRef`；
2. 37 个相同字节成员必须建立显式 `DERIVED_FROM` / `SOURCE_OF` 血缘边，不得跨包合并、去重或让一方覆盖另一方；
3. 0814 不得标记为 `ANALYSIS_VERSION`，也不得被描述为完整上游包；
4. 0808 不得被默认运行路径读取，避免历史脚本、ZIP 和非 Demo 内容扩大 Replay 的行为表面；
5. provenance 视图必须能从任一 0814 映射成员回到对应的 0808 成员，并显示两个包的独立身份。

## 4. 完整性缺口

必须声明以下 Gap Finding：

```text
S04_0808_PACKAGE_INTEGRITY_REFERENCES_MISSING_FROM_TRANSFER
```

原因：0808 的 `06_审计与交付/交付说明.md` 声称存在包级 `file_sha256_manifest.csv`，但当前移交目录中不存在该文件；`06_审计与交付/zip_sha256.csv` 引用外层 `SHRGT45_全信息基准版_20260808.zip`（1,835,237 B，SHA256 `aef0a53140807db93fb218a9214f67731f3a37b5e5f37b13e02e9e427c33beb2`），但该 ZIP 也未随移交资料提供。

因此状态必须分开记录：

```text
0808 content completeness by manifest file set = VERIFIED
0808 original authored package-seal completeness = PARTIAL
0808 -> 0814 lineage for 37 copied files = VERIFIED
```

这个 Finding 不允许 Adapter 猜测、补造或宣称原作者提供了当前 tree hash。它是否可 `ACCEPTED_FOR_REPLAY` 留待 D-008 和实际 `FIXTURE_IMPORT_REVIEW` 决定。

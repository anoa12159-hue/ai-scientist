# D-008 Replay Finding 处置政策请求

> 状态：`REQUEST_FOR_REVIEW`
>
> 决策上下文：`PROJECT_GOVERNANCE`
>
> 闸门：`GOV_REPLAY_FINDING_POLICY`

## 1. 背景

首个历史 Replay 会把流程 01-07 的适配结果转换为公共 `Artifact`、`Finding`、`ValidationReport` 和 `Lineage`。其中一部分是历史材料与当前契约之间的已知兼容性限制，另一部分则表示输入损坏、来源不明、配置漂移、未授权执行或报告 Join 失败。两者不能混成一个“Warning”状态：前者可以在人工审核时明确接受为历史回放限制，后者必须停止路径。

本请求只冻结政策，不替任何具体 Finding 创建运行时批准。每次 `HISTORICAL_REPLAY` 都必须在 `FIXTURE_IMPORT_REVIEW` 绑定本次 Run 的精确 `FindingRef`、`ArtifactRef`、必要的 `StageAttemptKey` 和哈希后，逐项产生不可变处置记录。

## 2. 选项

### A（推荐）：分层处置

允许下列已登记的历史兼容性/来源限制，在精确哈希绑定、可见警告和项目所有者批准后派生 `ACCEPTED_FOR_REPLAY`：

```text
MECHANISM_V23_VS_HYPOTHESIS_V22_DEPENDENCY
THEIL_SEN_VS_OLS_IMPLEMENTATION
LEAD_WINDOW_BOUNDARY_IMPLEMENTATION_MISMATCH
CONTROL_WINDOW_POLICY_MISMATCH
CONTROL_CATALOG_SPATIAL_ATTRIBUTION_UNFILTERED
HARP_NOAA_MAPPING_PARTIAL_OR_AMBIGUOUS
COUNTEREXAMPLE_INPUT_PACKAGE_IDENTITY_UNVERIFIED
EVENT_SEED_OFFICIAL_PROVENANCE_UNVERIFIED
HISTORICAL_ROWS_NOT_INDEPENDENT_SAMPLES
S04_0808_PACKAGE_INTEGRITY_REFERENCES_MISSING_FROM_TRANSFER
```

这些处置仅适用于当前批准的历史 Fixture Replay；它们仍是未解决限制，不得用于 Live Run、正式统计、科学结论或发布授权。`RESOLVE` 只能引用新 Artifact、Migration 或实现证据，不能靠人工备注消除。

以下情况无论如何不得由 `FIXTURE_IMPORT_REVIEW` 接受，必须 Fail Closed：

```text
unknown fixture path
missing required member
SHA256 mismatch
manifest mismatch
unknown Schema/version
unknown source/provenance identity
configuration hash mismatch
unauthorized formal execution
secret/credential access
script execution or ZIP extraction from inert 0808 bytes
S05/S06 required branch failure
Report Join failure
unbound Finding or Artifact
```

### B：所有 Finding 一律 Fail Closed

任何 Finding 都阻止 S07 和最终报告。该策略最保守，但历史 Replay 无法展示已知、已声明且可追溯的版本接缝，不能验证 MVP 的完整回放链路。

### C：接受所有已声明 Warning

所有标记为 Warning 的 Finding 均可接受，只要人工点击通过。该策略会把输入损坏、来源不明和 Join 失败与历史兼容性限制混淆，不符合失败关闭和可审计要求，不推荐。

## 3. 推荐选择

推荐 `A`。它把“可以带着限制回放”和“系统无法证明输入或执行正确”分开，同时保留逐项精确哈希审批、历史/Live 边界与失败关闭。

## 4. 回复格式

```text
D-008=A
actor_id=project_owner_01
补充意见=无
```

如选择 B 或 C，请说明如何处理已知历史兼容性限制，以及如何维持 `FIXTURE_IMPORT_REVIEW` 的精确 Finding/Artifact 绑定和 Fail Closed 语义。
